Privacy Policy: TSE Pipeline

Last updated: 27 September 2026

TSE Pipeline is a private publishing tool used only by the owner of the Top Search Everything YouTube channel.

What it accesses

With the channel owner's permission, it uses the YouTube Data API to upload videos and thumbnails to the owner's own YouTube channel. It does not read, collect or store data about any other person.

What it stores

The access token is stored as an encrypted secret in the owner's private GitHub repository. No user data is sold, shared or used for advertising.

Google API data

TSE Pipeline's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.
